# maintenance-mine

## راه‌اندازی پایگاه‌داده

1. برای ایجاد یا به‌روزرسانی ساختار پایگاه‌داده، دستور زیر را اجرا کنید:
   ```bash
   php backend/init_db.php
   ```
2. فایل پایگاه‌داده جدید در مسیر `backend/storage/database/maintenance.sqlite3` ذخیره می‌شود.
3. در اولین اجرای اسکریپت جدید، اگر فایل قدیمی با مسیر `backend/data/cmms.sqlite` وجود داشته باشد، به‌صورت خودکار در پوشه‌ی پشتیبان `backend/storage/backups/` با نامی شامل تاریخ و زمان کپی و سپس حذف می‌شود.

> **نکته:** پیش از هر بار اجرای مجدد اسکریپت، در صورت وجود داده‌های مهم، می‌توانید با کپی‌کردن فایل `backend/storage/database/maintenance.sqlite3` به مسیری امن، از آن پشتیبان تهیه کنید. برای بازگردانی، فایل پشتیبان را جایگزین همین مسیر کنید.

## توسعه

- تمامی درخواست‌های API از طریق فایل `backend/api.php` در دسترس هستند.
- برای اطمینان از وجود دایرکتوری‌های موردنیاز (دیتابیس، پشتیبان، آپلود) از تابع `ensure_data_dirs()` در `backend/db.php` استفاده شده است.
